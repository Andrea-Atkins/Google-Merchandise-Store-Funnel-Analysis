# Google-Merchandise-Store-Funnel-And-Conversion-Analysis
Analysis of real GA4 e-commerce event data to identify where users drop off in the shopping journey, and what that means for marketing and retention priorities.

Process:

Wrote SQL queries in BigQuery to answer business questions (funnel drop-off, channel/device performance, landing pages, seasonality, cart abandonment, new vs. returning visitors)
Cleaned and reshaped query results in Excel and Power Query
Built supporting calculations in DAX
Designed a two-page interactive Power BI dashboard with an intentional color system

Skills & tools: SQL | BigQuery | Excel | Power Query | DAX | Power BI | Data visualization | Funnel/segmentation analysis

Key finding: 

The funnel leaks early, at product engagement, not checkout   
Returning visitors convert 7x higher than new visitors despite being a small share of traffic.
