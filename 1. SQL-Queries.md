# SQL Queries — Funnel & Conversion Analysis

Dataset: `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`

---

### Q1 — Funnel stage conversion
*What's the conversion rate at each funnel stage, and where's the steepest drop-off?*

```sql
SELECT
  COUNT(DISTINCT CASE WHEN event_name = 'session_start' THEN user_pseudo_id END) AS sessions,
  COUNT(DISTINCT CASE WHEN event_name = 'view_item' THEN user_pseudo_id END) AS view_item,
  COUNT(DISTINCT CASE WHEN event_name = 'add_to_cart' THEN user_pseudo_id END) AS add_to_cart,
  COUNT(DISTINCT CASE WHEN event_name = 'begin_checkout' THEN user_pseudo_id END) AS begin_checkout,
  COUNT(DISTINCT CASE WHEN event_name = 'purchase' THEN user_pseudo_id END) AS purchase
FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
```

### Q2 — Channel performance
*Which acquisition channels convert best vs. bring high volume but weak conversion?*

```sql
SELECT
  traffic_source.medium AS channel,
  COUNT(DISTINCT CASE WHEN event_name = 'session_start' THEN user_pseudo_id END) AS sessions,
  COUNT(DISTINCT CASE WHEN event_name = 'purchase' THEN user_pseudo_id END) AS purchasers,
  ROUND(SAFE_DIVIDE(
    COUNT(DISTINCT CASE WHEN event_name = 'purchase' THEN user_pseudo_id END),
    COUNT(DISTINCT CASE WHEN event_name = 'session_start' THEN user_pseudo_id END)
  ) * 100, 2) AS conversion_rate_pct
FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
GROUP BY channel
ORDER BY sessions DESC
```

### Q4 — Landing page performance
*Which landing pages correlate with users progressing deeper into the funnel?*

```sql
WITH landing_pages AS (
  SELECT
    user_pseudo_id,
    (SELECT value.string_value FROM UNNEST(event_params) WHERE key = 'page_location') AS page_location,
    ROW_NUMBER() OVER (PARTITION BY user_pseudo_id ORDER BY event_timestamp ASC) AS rn
  FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
  WHERE event_name = 'page_view'
)
SELECT
  page_location AS landing_page,
  COUNT(DISTINCT user_pseudo_id) AS entries
FROM landing_pages
WHERE rn = 1
GROUP BY landing_page
ORDER BY entries DESC
LIMIT 20
```

### Q5 — Time trend / seasonality
*Are there day-of-week or seasonal patterns in conversion?*

```sql
SELECT
  event_date,
  FORMAT_DATE('%A', PARSE_DATE('%Y%m%d', event_date)) AS day_of_week,
  COUNT(DISTINCT CASE WHEN event_name = 'session_start' THEN user_pseudo_id END) AS sessions,
  COUNT(DISTINCT CASE WHEN event_name = 'purchase' THEN user_pseudo_id END) AS purchasers,
  ROUND(SAFE_DIVIDE(
    COUNT(DISTINCT CASE WHEN event_name = 'purchase' THEN user_pseudo_id END),
    COUNT(DISTINCT CASE WHEN event_name = 'session_start' THEN user_pseudo_id END)
  ) * 100, 2) AS conversion_rate_pct
FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
GROUP BY event_date, day_of_week
ORDER BY event_date
```

### Q6 — Cart abandonment
*What share of "add to cart" users never reach checkout?*

```sql
SELECT
  COUNT(DISTINCT CASE WHEN event_name = 'add_to_cart' THEN user_pseudo_id END) AS added_to_cart,
  COUNT(DISTINCT CASE WHEN event_name = 'begin_checkout' THEN user_pseudo_id END) AS reached_checkout,
  ROUND(SAFE_DIVIDE(
    COUNT(DISTINCT CASE WHEN event_name = 'add_to_cart' THEN user_pseudo_id END) -
    COUNT(DISTINCT CASE WHEN event_name = 'begin_checkout' THEN user_pseudo_id END),
    COUNT(DISTINCT CASE WHEN event_name = 'add_to_cart' THEN user_pseudo_id END)
  ) * 100, 2) AS abandonment_rate_pct
FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
```

### Q7 — New vs. returning visitors
*Do new vs. returning visitors convert differently?*

```sql
WITH user_type AS (
  SELECT DISTINCT user_pseudo_id,
    CASE WHEN COUNTIF(event_name = 'first_visit') OVER (PARTITION BY user_pseudo_id) > 0
         THEN 'new' ELSE 'returning' END AS visitor_type
  FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
)
SELECT
  u.visitor_type,
  COUNT(DISTINCT CASE WHEN e.event_name = 'session_start' THEN e.user_pseudo_id END) AS sessions,
  COUNT(DISTINCT CASE WHEN e.event_name = 'purchase' THEN e.user_pseudo_id END) AS purchasers,
  ROUND(SAFE_DIVIDE(
    COUNT(DISTINCT CASE WHEN e.event_name = 'purchase' THEN e.user_pseudo_id END),
    COUNT(DISTINCT CASE WHEN e.event_name = 'session_start' THEN e.user_pseudo_id END)
  ) * 100, 2) AS conversion_rate_pct
FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*` e
JOIN user_type u ON e.user_pseudo_id = u.user_pseudo_id
GROUP BY u.visitor_type
```
